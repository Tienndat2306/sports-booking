# BẢNG PHÂN CÔNG NHIỆM VỤ CHI TIẾT CHO 3 THÀNH VIÊN (A, B, C)

## 4. Quy Trình Phối Hợp Làm Việc Nhóm Trên Git

1. **Nhận code nền tảng:**
   ```powershell
   git clone <URL_REPO_CUA_NHOM>
   cd sportsbooking
   docker compose up -d
   .\mvnw.cmd spring-boot:run
   ```
2. **Quy tắc chia nhánh (Branching) để không bao giờ xung đột code:**
   - Nhánh `main`: Luôn ở trạng thái biên dịch và chạy thành công.
   - **Thành viên A** làm việc trên nhánh: `feature/member-a-booking`
   - **Thành viên B** làm việc trên nhánh: `feature/member-b-account-catalog`
   - **Thành viên C** làm việc trên nhánh: `feature/member-c-community-stats`
3. **Quy tắc dùng chung:**
   - Luôn trả về kết quả API bọc trong `ApiResponse.ok(message, data)` và ném lỗi qua `throw new AppException(ErrorCode.XXX, "Mô tả lỗi")`.
   - Luôn lấy tên khóa Redis từ [`RedisKeys.java`](file:///D:/NoSQL/DoAn/sportsbooking/src/main/java/com/huit/sportsbooking/model/redis/RedisKeys.java), sinh mã ULID từ [`IdGenerator.java`](file:///D:/NoSQL/DoAn/sportsbooking/src/main/java/com/huit/sportsbooking/common/IdGenerator.java), phát sự kiện Stream qua [`RedisStreamPublisher.java`](file:///D:/NoSQL/DoAn/sportsbooking/src/main/java/com/huit/sportsbooking/common/RedisStreamPublisher.java) và gửi thông báo realtime qua [`SseHub.java`](file:///D:/NoSQL/DoAn/sportsbooking/src/main/java/com/huit/sportsbooking/common/SseHub.java).
